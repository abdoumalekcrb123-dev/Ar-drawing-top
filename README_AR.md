# SketchTrace — مشروع أندرويد

هذا مشروع أولي قابل للبناء كتطبيق Android، ويحتوي على:
- معاينة مباشرة من الكاميرا الخلفية.
- اختيار صورة من معرض الهاتف.
- وضع الصورة فوق معاينة الكاميرا.
- التحكم في الشفافية والحجم والدوران.
- تحريك الصورة بإصبعك وإعادة ضبطها.

## إخراج APK
1. افتح المشروع في Android Studio.
2. اترك Gradle يحمّل الاعتماديات.
3. اختر Build ثم Build Bundle(s) / APK(s) ثم Build APK(s).
4. ستجد APK التجريبي داخل:
   `app/build/outputs/apk/debug/app-debug.apk`

للنشر في Google Play يجب إنشاء نسخة Release موقّعة، وإكمال متطلبات المتجر وسياسات الخصوصية.

## ملاحظة
هذه نسخة أولية عملية وليست نسخة متجر نهائية. يلزم اختبارها على عدة هواتف، وقد تحتاج إلى ضبط واجهة العرض حسب أبعاد الشاشة وإصدارات أندرويد.
